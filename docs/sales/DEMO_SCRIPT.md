# Demo Script (15 min)

## 0-2 min: Pain framing
- Как сейчас ведешь дедлайны/задачи/документы?
- Где чаще всего теряются дедлайны и версии?

## 2-9 min: Product demo
1) Dashboard: быстрый обзор прогресса
2) Applications: список вузов + статусы
3) Calendar: deadlines + tasks + drag/drop
4) Documents: версии и история

## 9-12 min: Trial setup
- 7 дней trial
- целевой результат: 3 вуза, 5 задач, 1 документ
- mid-trial check на день 5

## 12-15 min: Close
- фиксируем старт trial
- назначаем follow-up слот
- проговариваем цену после trial

## Demo checklist before each call
- Логин работает
- API доступен
- Календарь открывается без ошибок
- Есть подготовленные демо-данные
